# examcheck 편집기 개선 반영

비교 기준: `../examcheck/apps/web/src/features/templates` 및 해당 앱에서 사용하는
`examlist-template-editor-1.1.13-examcheck.21`의 편집기 코드.

## 적용한 동작

- **표 전체 복사·붙여넣기:** 표 테두리로 선택한 개체를 Ctrl+C/Ctrl+V로 복사한다. 열 너비, 행 높이, 셀 여백과 글자 서식을 유지하며 중복 ID와 선택 표시를 제거한다. 클립보드 HTML은 기존 문서 허용 목록으로 정리한다. 일반 텍스트와 입력 필드의 기본 복사는 유지한다.
- **데이터블록에 표 붙여넣기:** 표가 들어갈 공간이 부족하면 안내하고 삽입을 취소한다. 임의로 표를 축소하지 않는다. 편집 모달 취소는 원본에 영향을 주지 않고 적용 시 한 번 반영한다.
- **선택한 셀 내용 삭제:** Delete/Backspace는 셀의 내용만 비우며 표 구조와 다른 셀은 유지한다. 표 전체 개체 선택의 삭제 동작은 별도로 유지한다.
- **한글 조합 보호:** 이전 음절의 예약 갱신이 다음 음절의 조합을 방해하지 않도록 취소한다. 조합 중 문서 동기화와 편집기 단축키 처리를 보류하며 종료·분리된 편집기의 예약 작업은 실행하지 않는다.
- **줄별 정렬:** 하나의 문단에 BR로 구분된 여러 줄이 있어도 선택한 줄만 정렬한다. 빈 줄과 보호된 데이터 태그를 유지한다. 배분 정렬은 마지막 줄에도 적용되며 다른 정렬로 전환하면 해제된다.
- **서식 선택 유지와 실행 취소:** 글자 크기와 서식 변경 뒤 선택 영역을 유지한다. 일반 글자와 데이터 태그의 여러 내부 갱신을 한 번의 실행 취소로 묶는다. 글자 확대 시 줄 간격이 기존 크기에 고정되지 않도록 보완한다.
- **데이터 태그 뒤 커서:** 문단 끝의 데이터 태그 뒤에 글자를 입력할 수 있는 임시 커서 위치를 만든다. 임시 표시 문자는 저장하지 않고 실제 입력한 글자와 서식은 남긴다. 빈 문단에 태그를 삽입할 때 불필요한 줄바꿈을 제거한다.
- **표 크기 안정성:** 저장용 복사본처럼 화면 크기를 측정할 수 없는 상태에서 표를 줄이지 않는다. 데이터블록 확대 편집에서 셀 너비·높이 계산에 확대율을 반영하고, 기존 개체 뒤 커서 문단을 재사용한다.
- **빈 문서 편집:** 여러 빈 줄은 삭제할 수 있으며 마지막 입력 문단만 보호한다.
- **개체 행 배치:** examcheck의 행 공간 예약 방식을 기준으로 표·수험생 데이터 블록·이미지(바코드/QR 포함)의 페이지 배치를 통합했다. 이동·크기 변경 시 문장과 후속 개체가 함께 이동하며, 개체 순서도 저장 HTML에 반영한다. 확대율은 문서 좌표로 환산하고 자동 커서용 빈 문단은 추가 행 공간을 차지하지 않는다. 표 셀이나 데이터 블록 내부 개체는 해당 부모 영역에 유지한다.

## 통합 범위

React 작업공간 및 examcheck의 계정·업무 전용 데이터는 이식하지 않는다. 이미 있는 데이터블록, 페이지 번호, 개체 이동·크기 조절, 바코드·QR, 날짜 표시 형식은 현재 프로젝트의 연결과 데이터 형식을 유지한다.

편집 동작은 `client/template-editor-runtime`에 통합했다. HTML 정리 코드는
`shared/document-html-sanitizer.js`에서 공유하며 기존 호스트 모듈은 동일한 함수들을 다시 내보낸다.
저장 양식 스키마와 데이터베이스 마이그레이션은 변경하지 않는다.

## 검증

- `npm test`: 기존 회귀 검사, 연속 한글 조합·편집기 종료 검사, PDF 렌더링 시 정렬·표 크기 보존 검사.
- `npm run smoke:editor`: 계정이나 데이터베이스 없이 실제 Chromium에서 복사·붙여넣기, 선택 셀 삭제, 한글 입력, 줄 정렬, 선택 유지, 실행 취소·다시 실행, 태그 커서, 빈 줄 삭제, 데이터블록 모달 취소·적용 및 저장 HTML 복원을 검증한다.
- `npm run smoke:browser`: 현재 환경에서는 로그인 후 화면 전환 단계에서 중단되었다. 인증 이후 전체 애플리케이션 검증은 완료하지 못했다.
